# Panduan Pendaftaran Akun Guru
## Sistem Informasi DIKO – Dinas Pendidikan Kabupaten Kotawaringin Timur

### 1. Syarat Pendaftaran
- Memiliki **NIP** yang aktif.
- Memiliki **email** yang aktif.
- Menyiapkan **foto profil** (opsional, format JPG/PNG).

### 2. Cara Mendaftar

1. Buka halaman login aplikasi DIKO.
2. Klik tab **Daftar Guru**.
3. Isi form berikut:
   - **NIP** (wajib, hanya angka)
   - **Email** (wajib)
   - **Foto Profil** (opsional)
   - **Password** (minimal 8 karakter)
   - **Ulangi Password**
4. Klik tombol **Daftar sebagai Guru**.
5. Tunggu verifikasi dari admin Disdik.
6. Setelah disetujui, login menggunakan **NIP** sebagai username dan password yang sudah dibuat.

### 3. Setelah Akun Aktif

Setelah login, guru dapat mengakses:
- **Portal Guru** → tampilan mobile dengan profil, layanan kepegawaian, dan status usulan.
- Layanan yang tersedia:
  - Usul Mutasi
  - Permohonan Izin Perceraian (Mediasi)
- Status proses layanan:
  - Usulan
  - Sedang Proses
  - Rekomendasi Terbit (bisa dicetak)

### 4. Catatan
- Username login = **NIP**.
- Jika lupa password, gunakan fitur **Lupa Password** di halaman login (kode OTP dikirim via WhatsApp ke nomor yang terdaftar).
- Untuk bantuan lebih lanjut, hubungi admin Bidang Pembinaan Ketenagaan Dinas Pendidikan Kab. Kotim.
